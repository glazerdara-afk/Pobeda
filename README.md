# Сайт «Победа»

Одностраничный сайт: вёрстка и шрифты — векторные, взяты прямо из PDF-макета (`index.html`, внутри SVG).
5 блоков под видео/фото редактируются в `/admin`.

## Запуск
1. Создайте репозиторий на GitHub и загрузите все файлы из этой папки (ветка `main`).
2. Netlify → Add new site → Import from Git → выберите репозиторий (Build command пустой, Publish directory `.`).
3. Netlify → Site configuration → Identity → Enable Identity. Registration: Invite only.
4. Identity → Services → Git Gateway → Enable.
5. Identity → Invite users → пригласите свою почту, примите приглашение.
6. Откройте `https://ВАШ-САЙТ.netlify.app/admin/`, войдите.

## Редактирование
В `/admin` → «Видео и фото» → «5 блоков»: для каждого блока загрузите видео (mp4/webm) или фото и нажмите Publish.
Пока блок пуст, показывается оригинал из макета.
Совет: видео — mp4 (H.264), до ~20–30 МБ на файл, пропорции как у блока.

Блоки: 1 — ноутбук на камнях (верх), 2 — ноутбук на синем фоне, 3 — три карточки направлений, 4 — один телефон, 5 — три телефона.
